# 🧪 Testes E2E com Cypress - OrangeHRM

Este projeto contém testes automatizados End-to-End (E2E) para a validação do fluxo de autenticação na aplicação OrangeHRM utilizando o **Cypress**.

## 📌 Cenários Testados
- **login-success**: Valida o login com credenciais válidas e o redirecionamento correto para o Dashboard.
- **login-Fail**: Valida a exibição da mensagem de erro *"Invalid credentials"* ao informar dados incorretos.
